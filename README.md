# Networking Labs

> Practical networking studies, Cisco certification preparation, and hands-on exercises.

This repository documents networking concepts through structured courses, Packet Tracer activities, configuration exercises, and troubleshooting practice.

## Learning Tracks

| Track | Description |
|---|---|
| [CCNA 1 — Introduction to Networks](./netacad/ccna-1-introduction-to-networks/README.md) | Networking fundamentals, device configuration, IOS navigation, protocols, and physical-layer activities. |
| [CCNA 2 — Switching, Routing, and Wireless Essentials](./netacad/ccna-2-switching-routing-and-wireless-essentials/README.md) | Switching, routing, wireless networking, and practical network configuration. |
| [Jeremy's IT Lab — CCNA 200-301](./jeremys-it-lab/ccna-200-301/README.md) | Structured CCNA study notes, configuration exercises, and practical labs. |

## Tools

- Cisco Packet Tracer
- Cisco IOS
- Wireshark
- Git and GitHub

## Documentation

Each lab has its own directory and README. Numbering starts independently within each course.
